You are migrating book repos from a 2-tier (top, sub) topic schema to a 3-tier
(top, sub, leaf) schema. For every repo provided in the request, output the
correct (topCategory, subCategory, leafCategory) triple.

## Input

A JSON file at `ai-tasks/input/migrate-leaf-request.json` with shape:

```json
{
  "taskType": "migrateLeafTaxonomy",
  "promptFile": "templates/prompts/migrate-leaf.txt",
  "taxonomyFile": "templates/topic-taxonomy.yaml",
  "repos": [
    {
      "name": "atomic-habits",
      "description": "Atomic Habits | James Clear | A practical framework for ...",
      "currentTopics": ["hugobook", "nplus-portal", "nplus-kind-book", "sub-mindset", "top-personal"]
    }
  ]
}
```

The `currentTopics` shows the legacy 2-tier classification — use it as a strong
hint, but you may correct miscategorizations (especially books that belong in
`top-faith`; see below).

## Process

For each repo:

1. **Load the taxonomy whitelist** from `templates/topic-taxonomy.yaml`.
2. **Pick top + sub** from the whitelist. Prefer the existing `top-` and
   `sub-` from `currentTopics` unless you're confident the book belongs
   somewhere else (e.g. a deeply spiritual book currently under `top-wisdom`
   should move to `top-faith`).
3. **Pick leaf** from the leaf list under that sub in the taxonomy:
   - First fit: pick the closest existing `leaf-Z` name.
   - If no existing leaf fits well, propose a new kebab-case `leaf-Z` and
     mention it in the `reason` field — the human reviewer will decide
     whether to merge it with an existing leaf or add it permanently.
4. Write the result to `ai-tasks/output/migrate-leaf-response.json`.

## Output format

```json
{
  "results": [
    {
      "name": "atomic-habits",
      "topCategory": "personal",
      "subCategory": "mindset",
      "leafCategory": "growth",
      "reason": "Habit formation as identity-driven self-improvement → leaf-growth fits."
    }
  ]
}
```

Field rules:
- `name` — exact repo name from input (do not modify)
- `topCategory` / `subCategory` / `leafCategory` — kebab-case, **no prefix**
  (the CLI prepends `top-` / `sub-` / `leaf-` when computing the topic list)
- `reason` — one sentence, especially when proposing a NEW leaf

## Special case: top-faith

Move books to `top-faith` if their primary intent is Christian theology, biblical studies,
prayer, devotional life, or pastoral practice — even if they were previously
under `top-wisdom + sub-theology`. Books on comparative religion or general
philosophy of religion stay in `top-wisdom`.

## Constraints

- Do NOT invent new `top-` or `sub-` values; those are fixed by the taxonomy.
- New `leaf-` values are allowed but should be lowercase, kebab-case,
  noun-phrase, and applicable to multiple books (don't create one-off leafs
  for a single book — fall back to a broader existing leaf instead).
- Output MUST be valid JSON, no markdown fences, no explanations outside the
  JSON file.
